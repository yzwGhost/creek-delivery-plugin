# yunxiao

探测连接、目标项目、用例及缺陷的查询、新增、更新权限和必填字段。每轮按下列模板展示全部行和字段的实际值，保存清单版本及摘要，取得用户对该项目和该版本的明确确认。修改任何实质内容均使确认失效。无权限或缺字段保留待同步清单、原因及恢复条件；其他工作继续。

从测试用例和缺陷记录提取字段生成同步清单，核对目标库字段和实际内容，避免手工重复录入；向用户展示完整清单并确认后方可写入。

逐条先登记写入中，再调用实际工具，保存返回 ID、状态与时间。恢复时跳过已成功项；确定未写入的失败项修正原因后可重试，修改清单则重新确认。超时、连接中断、写入中或返回未知均先按远端 ID 或稳定标记查询，再核对项目与完整内容；一致则补记成功，权威查询确认未写入后方可重试。无法判定、冲突或多重匹配标记待核对，停止该项。
用户确认绑定到目标项目、完整清单版本和内容摘要。更换目标项目或清单内容发生变化时，原确认失效，展示完整新清单并重新确认。
